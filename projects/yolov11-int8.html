A reproducible host/device toolkit for quantizing object detection on Jetson Orin NX while keeping every accuracy regression visible at the class level.

The problem

Speed is useful only when accuracy accounting is honest.

Aggregate mAP can hide the exact classes damaged by INT8 quantization. This project treats conversion as an auditable engineering decision: establish FP32 and FP16 baselines, sweep calibration choices, compare every class, and add FP16 back only where the evidence supports it.

Design principle

No Jetson latency, power, memory, or accuracy number is hand-entered. Device measurements must be produced by committed scripts and rendered from raw JSON.

System design

A host/device split that remains testable without the target hardware.

  1. Export and baseline

    Lock preprocessing and input shapes, export YOLOv11s to ONNX, then build FP32 and FP16 TensorRT engines.

  2. Calibrate systematically

    Compare entropy and min-max activation scales at 32, 128, and 512 images with reproducible subsets and cached calibration artifacts.

  3. Audit accuracy

    Compute COCO-style mAP@50 and mAP@50-95 per class and flag any absolute drop above two percentage points.

  4. Rank sensitive layers

    Use SQNR to identify poorly represented activations and generate top-1, top-3, and top-5 selective FP16 plans.

  5. Measure on device

    Run locked-clock accuracy and 1,000-iteration latency benchmarks on Jetson Orin NX, then render the report from raw outputs.

Engineering decisions

Precision is assigned by failure mode, not by habit.

Calibration selection

Entropy calibration is expected to preserve resolution for the bulk of heavy-tailed detection activations, while min-max avoids clipping. The committed rule selects the higher mAP@50-95 result and breaks ties using the number of flagged classes.

Fused DFL decode

A custom TensorRT plugin fuses softmax and expectation for the distribution-focal-loss decode. It stays in FP32 because global normalization is precision-sensitive; the host reference passes at approximately 2.6e-6 maximum absolute error.

Selective fallback

The deployment ladder adds FP16 to the lowest-SQNR layers until class regressions clear, then stops. This makes the accuracy-per-millisecond trade-off explicit.

Evidence & limits

What is proven—and what is still pending.

  • The host-side calibration, mAP, sensitivity, precision-planning, reporting, and plugin-reference layers are covered by 56 automated tests.
  • Device scripts capture mean and p99 latency, throughput, INA3221 power, memory delta, aggregate mAP, and per-class deltas.
  • The published benchmark table intentionally remains blank until a real Orin run supplies the raw measurement files.
Next milestone

Execute the full engine matrix on Jetson Orin NX, populate the benchmark report, and select the final mixed-precision configuration using the committed rules.

AI Content & Campaign Engine

A multi-agent pipeline that expands one product keyword into a structured brief, multi-channel copy, explainable SEO quality reports, and four ranked advertising angles - with Claude generation or a deterministic offline mode.

The problem

Generating copy is easy; producing a testable campaign system is harder.

A marketing workflow needs consistent inputs, distinct channel outputs, quality feedback, and alternatives that test different hypotheses. This engine separates planning, writing, scoring, and experimentation so each stage has a clear responsibility.

System principle

The model writes the copy, but pure Python calculates quality scores and ranking. The acceptance gate remains reproducible even when generation varies.

Agent architecture

Specialized stages turn one keyword into a campaign package.

  1. Capture campaign context

    The interface accepts a product keyword, brand, audience, tone, and desired number of variants.

  2. Build the brief

    BriefAgent expands the request into selling points and a focused SEO keyword set.

  3. Create channel assets

    CopywriterAgent produces an approximately 120-word blog introduction, a 40-60 word advertisement, and two social posts.

  4. Score quality deterministically

    A pure-Python scorer checks keyword use, density, placement, length, Flesch readability, and call-to-action presence.

  5. Generate and rank tests

    ABVariantAgent creates value, urgency, social-proof, and curiosity angles; the scorer ranks the resulting ads and selects a winner.

Provider design

The full product remains demonstrable without an API key.

When an Anthropic key is available, Claude powers the generative agents. Otherwise a deterministic offline provider returns structured content through the same pipeline. The Streamlit interface exposes the active mode, while the command-line smoke test exercises the end-to-end offline path.

Why the split matters

Provider abstraction keeps orchestration, scoring, ranking, and interface behavior testable without network cost. It also isolates generated text from the deterministic evaluation layer.

Outputs

One run produces content and an experiment plan.

  • A product brief with selling points and SEO keywords.
  • Blog, ad, and social copy with per-asset 0-100 reports and improvement suggestions.
  • Four deliberately different ad angles rather than minor wording variants.
  • A ranked winner selected by the same explainable scoring contract.
  • An offline smoke test that checks nonempty outputs, valid score bounds, variants, and winner selection.

Limits & next steps

An SEO heuristic is a quality gate, not campaign performance.

  • The score measures textual rules; it does not predict click-through rate, conversion, or brand lift.
  • Flesch readability and keyword density can reward mechanical copy if treated as objectives rather than guardrails.
  • The current ranking should be combined with human brand review before publication.
  • Production learning requires impression, click, conversion, cost, and audience assignment data from a real randomized test.
Next milestone

Add structured brand constraints and an experiment-results loop so creative ranking can move from heuristic SEO quality to observed incremental campaign performance.

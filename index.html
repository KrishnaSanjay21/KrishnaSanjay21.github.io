Case study → Code ↗

YOLOv11s INT8 TensorRT Audit Suite

Host/device validation toolkit for converting YOLOv11s from FP32 to FP16 and INT8 on NVIDIA Jetson Orin NX without hiding per-class regressions.

  • 56 passing tests across calibration, accuracy, sensitivity, and plugin behavior.
  • Per-class mAP comparison and selective FP16 fallback planning.

FP32 model → calibration → TensorRT INT8 → accuracy audit

Detailed architecture
  1. 01Export

    Ultralytics YOLOv11s weights are exported to ONNX with locked input shapes and preprocessing assumptions.

  2. 02Build baselines

    FP32 and FP16 TensorRT engines establish accuracy and latency baselines before quantization.

  3. 03Calibrate INT8

    Entropy and min-max calibrators run 32, 128, and 512-image sweeps with reusable calibration caches.

  4. 04Audit accuracy

    COCO-style per-class mAP and output-difference checks flag regressions greater than two percent.

  5. 05Plan precision

    SQNR sensitivity ranks fragile layers and produces selective FP16 fallback plans for Jetson deployment.

Execution split
NumPy/pytest validation runs on any host; TensorRT, CUDA, engine builds, and benchmarks run on Jetson Orin NX.
Outputs
Engine files, raw benchmark JSON, per-class accuracy tables, precision decisions, and a rendered benchmark report.

07 / Forecasting
Case study → Code ↗

Retail Demand Forecasting

Leakage-safe SKU forecasting pipeline that connects chronological backtesting to safety-stock and reorder-point decisions.

  • Reports WAPE, MAE, RMSE, bias, intervals, and baseline improvement.
  • Supports the UCI Online Retail II dataset with more than one million transactions.

Transactions → lag features → backtest → inventory plan

Detailed architecture
  1. 01Prepare demand

    Synthetic data or UCI Online Retail II transactions are cleaned, returns are excluded, and sales are aggregated by SKU and day.

  2. 02Build features

    Shifted lags, rolling statistics, calendar signals, price, and promotion features prevent target leakage.

  3. 03Backtest

    Ridge forecasts the most recent chronological window and is compared with a seven-day seasonal-naive baseline.

  4. 04Plan inventory

    Residual-based 90% intervals feed service-level safety-stock and reorder-point calculations for each SKU.

Evaluation
Per-SKU WAPE, MAE, RMSE, bias, interval coverage, and baseline improvement are reported.
Outputs
HTML report, backtest forecasts, portfolio summary JSON, and SKU-level inventory recommendations.

08 / Decision Science
Case study → Code ↗

Causal Uplift & Experimentation

Randomized-experiment analysis and two-model uplift pipeline for identifying customers who convert because of treatment.

  • ATE, confidence intervals, uplift curves, and incremental-conversion evaluation.
  • Adapter for the corrected 14-million-row Criteo uplift dataset.

RCT → effect estimate → uplift model → targeting policy

Detailed architecture
  1. 01Ingest experiment

    A reproducible synthetic RCT or corrected Criteo uplift data supplies features, treatment assignment, and conversion outcomes.

  2. 02Measure experiment

    Treatment and control rates produce absolute lift, relative lift, p-values, and 95% confidence intervals.

  3. 03Estimate uplift

    Separate regularized logistic models estimate treated and untreated response probabilities; their difference is the CATE score.

  4. 04Build policy

    Customers are ranked into deciles and evaluated with uplift curves and observed incremental conversions.

Validation
Randomized outcomes—not classifier accuracy alone—measure whether the targeting policy creates incremental value.
Outputs
Experiment summary JSON, uplift segments, uplift-curve data, automated tests, and an HTML decision report.

09 / Statistical ML
Case study → Code ↗ Read report ↗

US Homicide Clearance Analysis

Long-run analysis of FBI case data examining the relationship between increasingly anonymous homicides and declining clearance rates.

  • 47 years of data; engineered anonymity feature correlated at r = −0.73.
  • Degree-three polynomial model achieved R² = 0.81 and 1.32% MAE.

FBI cases → feature engineering → model comparison → forecast

Detailed architecture
  1. 01Ingest

    FBI Supplementary Homicide Report case records from 1976–2023 are cleaned and aggregated into national annual measures.

  2. 02Engineer signals

    Relationship categories are consolidated into an “Anonymous” feature representing stranger and unknown-offender cases.

  3. 03Compare models

    Polynomial regression, random forest, and SVR are evaluated for historical fit and their ability to extrapolate over time.

  4. 04Report findings

    The selected degree-three model supports the forecast while Plotly, Power BI, and LaTeX communicate evidence and limitations.

Model decision
Tree models fit historical data strongly but flatten outside the training range; polynomial regression better preserves the long-run trend.
Outputs
Notebook analysis, correlation and forecast visualizations, and a linked formal PDF report.
